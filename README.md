# mini-app

这是一个用于后续业务迭代的微信小程序初始化工程，当前提供最小可运行骨架、默认首页与 OpenSpec 需求文档。

## 目录说明

- `app.*`：小程序应用入口与全局配置
- `pages/index/`：默认首页
- `utils/`：公共常量与扩展入口
- `scripts/`：本地校验脚本
- `openspec/`：需求、设计与任务文档

## 本地准备

1. 确保本机安装 Node.js 20 或更高版本。
2. 在项目根目录执行 `npm run check`，确认关键文件齐全。
3. 打开微信开发者工具，选择“导入项目”。
4. 项目目录选择当前 `mini-app` 根目录。
5. `AppID` 可先使用测试号或保持 `touristappid` 进行本地体验。

## 调试方式

- 使用微信开发者工具打开项目后，默认进入首页 `pages/index/index`。
- 如需检查目录结构是否完整，可执行 `npm run check`。

## 后续扩展建议

- 新页面放入 `pages/` 目录，并在 `app.json` 中注册。
- 公共工具函数与常量优先放入 `utils/`。
- 新需求优先在 `openspec/` 中补充或新增变更，再进入实现阶段。
